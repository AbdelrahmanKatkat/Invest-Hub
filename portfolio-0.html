Modern portfolio theory

The questionIs picking "good" individual assets the same problem as building a "good" portfolio?

Intuition

Modern portfolio theory treats portfolio construction as a whole-portfolio optimisation problem, not an asset-by-asset one — exactly the diversification math from Investment Fundamentals Lesson 0.7, generalised to many assets at once.

Worked example

Recall: two assets, each σ=20%, correlation 0.3, blended 50/50, gave a portfolio σ of about 16.1% — lower than either asset alone. MPT asks: for a given target risk, which exact mix of many assets maximises expected return?

Try this
  1. Revisit the two-asset diversification lab and vary correlation — the same mechanism scales to many assets.
Common traps
  • MPT relies on estimated returns, risks and correlations — the output is only as good as those estimates.
Where it shows up in real investing
  • Most target-date and robo-advisor allocation models trace back to MPT.

Check yourself

1. Is MPT an asset-by-asset or whole-portfolio approach?
Whole-portfolio.
2. What three inputs does MPT need per asset/pair?
Expected return, risk (σ), and correlation with other assets.
3. Is MPT's output only as good as what?
Its input estimates — garbage in, garbage out.

Takeaways

  • MPT generalises two-asset diversification to a whole portfolio.
  • Its quality depends entirely on its input estimates.

The efficient frontier

The questionTwo portfolios have the same expected return, but one has lower risk. Is there ever a reason to hold the higher-risk one?

Intuition

The efficient frontier is the set of portfolios offering the best possible expected return for each level of risk. A portfolio below the frontier is dominated — some other portfolio offers more return for the same risk, or less risk for the same return, so there's no good reason to hold the dominated one.

Worked example

A stylised frontier shape, return rising with the square root of risk: at risk 9% the frontier might offer about 6% return; at risk 16% about 8% — return keeps rising with risk, but at a decreasing rate.

\text{Return}\approx a\sqrt{\text{Risk}}+b
Try this
  1. Pick a risk level and read the frontier's return; any portfolio below that curve at the same risk is dominated.
Common traps
  • The frontier is built from estimates and shifts as those estimates change — it isn't a fixed, known curve in the real world.
Where it shows up in real investing
  • Portfolio optimisation tools plot and select portfolios along an estimated frontier.

Check yourself

1. What does "dominated" mean for a portfolio?
Some other portfolio offers more return for the same risk, or less risk for the same return.
2. Is there ever a good reason to hold a dominated portfolio?
Generally no, if the frontier estimate is accurate.
3. Is the real-world efficient frontier a fixed, known curve?
No — it's built from estimates that shift over time.

Takeaways

  • The efficient frontier shows the best return available at each risk level.
  • It's an estimate, not a fixed fact.

CAPM & beta

The questionRisk-free rate 2%, the market is expected to return 8%, and a stock has a beta of 1.3. What return does CAPM suggest is "fair" for that stock's risk?

Intuition

Beta measures an asset's sensitivity to overall market moves (beta of 1.3 means it tends to move about 30% more than the market). The Capital Asset Pricing Model (CAPM) uses beta to estimate a "fair" expected return for that level of market-related risk.

Worked example

2% + 1.3×(8% − 2%) = 2% + 7.8% = 9.8%.

E[R]=R_f+\beta\,(R_m-R_f)
Rfrisk-free rate
Rmexpected market return
βsensitivity to market moves
Try this
  1. Set beta to 1: CAPM gives exactly the market return — no more, no less.
Common traps
  • CAPM uses one factor (market beta) — it's a simplification, not a complete description of risk (Lesson "factor-investing-intro" adds more).
Where it shows up in real investing
  • Beta is reported on virtually every stock's profile.

Check yourself

1. What does a beta of 1.3 mean?
The asset tends to move about 30% more than the overall market, in the same direction.
2. Rf=3%, Rm=9%, beta=0.8. CAPM expected return?
3 + 0.8×6 = 7.8%.
3. Is CAPM a complete description of risk?
No — it's a one-factor simplification.

Takeaways

  • Beta measures sensitivity to the overall market.
  • CAPM estimates a fair expected return from beta alone — a simplification.

Factor investing, briefly

The questionCAPM uses one factor (the market). What if more than one shared characteristic helps explain returns across many stocks?

Intuition

Factor investing extends CAPM's single market factor to several (such as value, size or quality), each with its own exposure coefficient. A stock's expected return becomes a combination of several factor exposures, not just one.

Worked example

A simplified two-factor estimate: E[R] = 2% + 1.1×(market premium 6%) + 0.5×(value premium 3%) = 2 + 6.6 + 1.5 = 10.1%.

E[R]=R_f+\sum_k \beta_k\,(\text{factor premium}_k)
Try this
  1. Raise the value-factor exposure: the estimated expected return rises, holding the market exposure fixed.
Common traps
  • More factors can fit historical data better while still not reliably predicting the future — a close cousin of overfitting (Quant Investing).
Where it shows up in real investing
  • "Smart beta" and factor ETFs built around specific factor exposures.

Check yourself

1. How does factor investing extend CAPM?
By adding more than one shared-characteristic factor instead of only the market.
2. Does more factors always mean a more reliable model?
Not necessarily — more factors can overfit past data without improving future predictions.
3. Name an example of a commonly discussed factor.
Any of: value, size, momentum, quality.

Takeaways

  • Factor models generalise CAPM to multiple shared characteristics.
  • More factors isn't automatically better.

Rebalancing policies in depth

The questionShould you rebalance every month, every year, or only once drift crosses some threshold?

Intuition

Building on Investment Fundamentals Lesson 4.2: a calendar policy rebalances on a fixed schedule regardless of drift size; a threshold policy rebalances only once drift exceeds a set amount. More frequent rebalancing controls drift more tightly but costs more in trading (and, in taxable accounts, potential taxes).

Worked example

A threshold policy set to trigger at 5% drift rebalances less often than one set at 2% drift, trading fewer times per year but allowing more drift from target in between.

\text{trigger}: |\text{current weight}-\text{target weight}|>\text{threshold}
Try this
  1. Lower the threshold: more of a given drift range triggers a rebalance — tighter control, more frequent trading.
Common traps
  • Very tight thresholds can generate excessive trading costs relative to the drift they correct.
Where it shows up in real investing
  • Target-date funds' internal rebalancing schedules commonly combine both calendar and threshold elements.

Check yourself

1. What's the difference between calendar and threshold rebalancing?
Calendar rebalances on a fixed schedule; threshold rebalances only once drift exceeds a set amount.
2. Current weight 68%, target 60%, threshold 5pp. Does it trigger?
Drift = 8pp > 5pp threshold, so yes.
3. What's the trade-off of a very tight threshold?
Tighter drift control but more frequent trading and costs.

Takeaways

  • Rebalancing policy trades drift control against trading cost.
  • Calendar and threshold approaches can be combined.
