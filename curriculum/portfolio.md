# Portfolio Management — curriculum spec

**End state:** describe modern portfolio theory, the efficient frontier, CAPM/beta, factor investing and rebalancing
policy well enough to reason about a real portfolio's construction. **Status:** Module 0 is a basic pass; builds on
Investment Fundamentals Lessons 0.7 (diversification) and 4.2 (rebalancing).

## Module 0 · Foundations  (`portfolio-0.html`)
| id | Lesson | Must understand | Real-world link |
|---|---|---|---|
| modern-portfolio-theory | Modern portfolio theory | Combining assets optimally for risk and return is a portfolio-wide problem, not an asset-by-asset one | MPT underlies most target-date and robo-advisor allocation models |
| efficient-frontier | The efficient frontier | The set of portfolios offering the best possible expected return for each level of risk; portfolios below it are "dominated" | Portfolio optimizers plot and select along this frontier |
| capm-and-beta | CAPM & beta | Beta measures an asset's sensitivity to the overall market; CAPM estimates expected return from it | Beta reported on virtually every stock's profile |
| factor-investing-intro | Factor investing, briefly | Returns can be partly explained by shared characteristics (factors) across many securities, not just the market as a whole | "Smart beta" and factor ETFs |
| rebalancing-policies | Rebalancing policies in depth | Calendar vs. threshold rebalancing trade off simplicity, cost and how tightly drift is controlled | Target-date funds' internal rebalancing schedules |
